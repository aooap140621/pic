# pic

이미지 링크용 공개 저장소입니다. PNG, JPG, 애니메이션 WebP를 웹에서 바로 올릴 수 있습니다.

## 이미지 올리기

[여기를 눌러 이미지 업로드](https://github.com/aooap140621/pic/upload/main)

1. 위 링크 또는 저장소의 **Add file → Upload files**를 선택합니다.
2. 이미지 파일을 끌어다 놓거나 **Choose your files**로 선택합니다.
3. **Commit changes**를 눌러 저장합니다.
4. 아래 주소에서 파일 이름을 실제 업로드한 이름으로 바꿔 사용합니다.

```text
https://raw.githubusercontent.com/aooap140621/pic/main/파일이름.webp
```

## 파일 이름

- 영문 소문자, 숫자, 하이픈을 쓰면 주소를 다루기 편합니다.
- 파일 이름의 대소문자와 확장자는 주소와 정확히 같아야 합니다.
- 폴더에 넣은 파일은 주소에도 폴더 이름을 포함하세요.
- 이 저장소의 파일은 누구나 볼 수 있습니다.
